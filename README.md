ICM InfoWorks - What's New

ICM InfoWorks - What's New is an interactive, AI-powered release-notes explorer that turns static ICM InfoWorks release documentation into a searchable, visual, and conversational product history. It covers 48 versions from v1.5 through v2027.0 and about 809 documented features, with a browsable timeline, full-text search, category filters, a Compare Versions workflow for upgrade-path analysis, and automatically detected feature-evolution chains.

An analytics dashboard visualizes feature activity as a category by version heatmap, and a My Stack tracker shows what is new relative to a baseline version you select. The app also includes a chat sidebar backed by four AI models, Claude, DeepSeek, Gemini, and GPT-4o Mini, each of which answers questions about releases and features with clickable citations that jump to the relevant timeline entry. The frontend is React, TypeScript, and Vite, and the backend is Express, with version data served from an in-memory dataset.
